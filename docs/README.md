# PharmaSee documentation

PharmaSee helps clients find verified pharmacies with the medicine they need in stock and get directions for an in-person purchase. Pharmacy owners manage inventory, sales, returns, expenses, and profit.

|---|---|

| [Business rules and data model](business-rules.md) | Inventory movements, sales, returns, expenses, and reporting |

| [API contract](openapi.json) | Draft OpenAPI endpoints and schemas |
| [Technical design](technical-design.md) | System boundaries and integration decisions |
